# CodeLearn — Онлайн курси Python / JavaScript

## Опис проєкту

CodeLearn — це сучасний адаптивний веб-застосунок для онлайн-навчання Python та JavaScript. Проєкт був створений у три основні етапи: дизайн інтерфейсу у Figma, верстка HTML+CSS та реалізація інтерактивності за допомогою JavaScript.

# Етап 1 — Дизайн у Figma

На першому етапі було створено UI/UX-дизайн веб-застосунку у Figma для desktop та mobile версій.

## Основні вимоги етапу:

* створення desktop та mobile макетів;
* використання Auto Layout;
* використання компонентів та текстових стилів;
* побудова Grid-сітки;
* створення адаптивного дизайну;
* використання іконок, фотографій та ілюстрацій;
* створення hover-станів та інтерактивних елементів;
* побудова правильної ієрархії заголовків;
* організація охайної структури шарів та фреймів;
* створення прототипів навігації та взаємодії.

## Структура секцій:

1. Header
2. Hero Section
3. Features Section
4. Learning Steps Section
5. Testimonials Section
6. CTA Section
7. Footer

# Етап 2 — HTML + CSS

На другому етапі було виконано адаптивну семантичну верстку веб-застосунку.

## Основні вимоги етапу:

* використання HTML5-семантики;
* використання тегів:
* `<header>`
* `<main>`
* `<section>`
* `<article>`
* `<nav>`
* `<footer>`;
* правильна ієрархія заголовків;
* використання методології BEM;
* адаптивність через CSS Grid та Flexbox;
* реалізація Fluid Design;
* використання media queries;
* реалізація hover-ефектів;
* sticky/fixed header;
* плавна прокрутка сторінки;
* використання CSS-змінних;
* box-sizing: border-box;
* адаптація desktop та mobile версій;
* оптимізація зображень та SVG-іконок.

## Використані технології:

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries
* BEM Methodology

# Етап 3 — JavaScript Інтерактивність

На третьому етапі було реалізовано інтерактивність інтерфейсу за допомогою JavaScript.

## Основні вимоги етапу:

* sticky header при скролі;
* приховування header при прокрутці вниз;
* поява header при прокрутці вгору;
* burger-меню для mobile версії;
* slider відгуків студентів;
* Cookie Bar зі збереженням у localStorage;
* Go Top кнопка;
* плавна прокрутка;
* анімації елементів при першому скролі;
* модальне вікно з формою;
* валідація email через RegExp;
* success-message та error-message;
* відкриття/закриття модального вікна;
* інтерактивні hover-ефекти;
* реалізація без використання сторонніх бібліотек.

## Реалізовані компоненти:

* Sticky Header
* Mobile Burger Menu
* Testimonials Slider
* Cookie Bar
* Modal Window
* Form Validation
* Scroll Animations
* Go Top Button
